# Проверка возможности упростить модель

Ни одно упрощение не выполнило все условия. `Usage ensemble` и
`results/selected_model.joblib` сохранены; кандидата нет. Отдельный скрипт
проверил сохранённые предсказания, пересчитал метрики и условия выбора,
подтвердил сохранность исторических файлов.

Цель — сократить число компонентов и улучшить оценку доступных машин при росте
общей MAE ≤3%. MAE — средняя абсолютная ошибка. Протокол зафиксирован до обучения:
`experiments/simplicity_review/PROTOCOL.md`:

- A, `single_mae`: одна ANN с возрастом и расчётным годовым пробегом, эпоха по внутренней MAE.
- B, `single_log`: та же траектория ANN, эпоха по абсолютной ошибке log1p цены.
- C, `single_forest`: 75% прогноза A + 25% Random Forest.
- D, `historical_recipe`: десять ANN и лес, заново обученные в каждом фолде;
  проверяется рецепт.

## Почему замены нет

Упрощение должно одновременно выполнить четыре условия относительно D:

1. Общая MAE не выше 103% MAE варианта D.
2. Общих попаданий ±20% не меньше.
3. Попаданий Q1 и Q2 не меньше отдельно в каждой группе, хотя бы в одной больше.
4. Медианная APE машин ≤6,7 млн ₸ не выше.

У A и B рост MAE превышает 3%. У C он допустим, но на 23 общих попадания и
семь попаданий Q2 меньше, а медианная APE доступных машин выше. Одного
дополнительного попадания Q1 недостаточно. Условия не смягчаются;
дополнительный поиск после результата не проводится.

## Как понимать проверку

Использованы 1 787 строк TRAIN. Пять внешних фолдов дают строке прогноз без
обучения на ней (OOF). Внутренние 20% выбирают эпоху; преобразователи признаков
и цели обучаются на остальной внутренней части. Исходные 383 validation и
383 test исключены. Ценовые группы используются для оценки и стратификации;
переключения модели по известной цене нет.

Это результат разработки: данные уже влияли на прошлые решения, а OOF
используется для выбора рецепта. Он не является независимой оценкой на новых
объявлениях и напрямую не сравнивается со старыми метриками 383 test.
Одно попадание не доказывает устойчивого улучшения. Фолды, предсказания,
истории и хеши сохранены в `results/simplicity_review/`.

Сравнение сохраняет обязательные части курса: медианный
baseline, Linear Regression, KNN, Decision Tree, настройку с CV, обычную ANN,
EDA, K-Means и PCA. Источник — цены объявлений 2025 года, не сделки или рынок
2026 года. Личный вклад студентов и участие в защите требуют подтверждения.

Из `endterm_code` в окружении проекта Python 3.12, проверка без обучения:

```bash
python experiments/simplicity_review/verify_simplicity_review.py --project-source . --output-dir results/simplicity_review
```

Повторный расчёт — только в новую папку:

```bash
python experiments/simplicity_review/run_simplicity_review.py --project-source . --output-dir results/simplicity_review_new
python experiments/simplicity_review/verify_simplicity_review.py --project-source . --output-dir results/simplicity_review_new
```
