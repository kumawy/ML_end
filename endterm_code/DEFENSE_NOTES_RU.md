## Короткие ответы на ожидаемые вопросы

- **Почему MAE?** Ошибка выражается в тенге и меньше зависит от отдельных дорогих объявлений, чем RMSE. RMSE дополнительно показывает влияние крупных ошибок.
- **Что значит R² = 0.917?** Относительное снижение суммы квадратов ошибок по сравнению с предсказанием средней цены в test. Это не 91.7% точных оценок.
- **Почему final ensemble, если у single ANN меньше RMSE?** Выбранный рецепт учитывает MAE и попадания в интервал ±20%. Разные метрики дают разные ранги.
- **Есть ли утечка?** Preprocessing и target scaling обучаются на training, CV работает внутри training. Однако прежние ошибки historical test влияли на гипотезы разработки. Поэтому результаты ретроспективные, без заявления о независимом обобщении.
- **Что означает dual checkpoint?** Эпоха с минимальным score 0.5 × (MAE / reference MAE + miss20 / reference miss20), где miss20 — доля ошибок свыше 20%. Это отдельный checkpoint, а не среднее двух эпох.
- **Как усредняются прогнозы?** Каждая сеть сначала возвращает цену из стандартизованного log1p в KZT. После этого ансамбль усредняет денежные прогнозы.
- **Почему возраст привязан к 2025?** Это год snapshot. Дат отдельных публикаций нет. Формула не зависит от текущей даты и не использует цену.
- **Что дают K-Means и PCA?** Описывают numeric-геометрию training. Цена не входит в их fit, PCA не используется конечной моделью.
- **Какие ограничения?** Цены объявлений, один historical split, повторное использование test, редкие дорогие модели, отсутствие подтверждённого состояния автомобиля. Нужна свежая независимая выборка.
